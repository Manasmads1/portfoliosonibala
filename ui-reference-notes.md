# Motion UI references used

- https://skiper-ui.com/components — used for the interaction direction: mouse-follow animations, image/cursor trail, drawing cursor effect, gradient hover cards, card-stack scroll, text-scroll animation, and SVG follow-scroll patterns.
- https://threeui.com/ — used for the direction of restrained 3D surfaces, pointer-reactive backgrounds, glass buttons, particle/orb interaction, and motion-design sections.
- https://21st.dev/ — used for the production approach: own the React/TypeScript components locally, use polished component patterns, and avoid external runtime lock-in.

The implementation is original project code rather than a copied premium component. The visual language stays corporate: dark graphite, cool steel type, controlled violet/coral accents, readable Manrope body copy, and reduced-motion/touch safeguards.
